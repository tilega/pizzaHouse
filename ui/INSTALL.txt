PIZZA HOUSE — ОНОВЛЕННЯ КЛІЄНТСЬКОЇ ЧАСТИНИ

1. Закрийте Pizza House та зробіть резервну копію ВСІЄЇ папки проєкту.
2. Скопіюйте вміст цього архіву в папку pizzaHouse, зберігаючи структуру ui/.
3. НЕ видаляйте і НЕ замінюйте свій pizza_house.db. Його немає в архіві.
4. НЕ замінюйте власні фото в assets/menu_photos — в архіві ця папка порожня.
5. Встановіть залежності: py -3.13 -m pip install -r requirements.txt
6. Запустіть pizzaHouse.py у Visual Studio.

Ролі:
- Гість: Меню, Кошик; оформлює замовлення без customer_id.
- Зареєстрований клієнт: Меню, Кошик, Історія замовлень, Акаунт.
- Адміністратор: усі сім адміністративних вкладок.
- Демовхід client / 1234 прив'язано до тестового клієнта C1042.
- Для власного нового клієнта є кнопка «Створити акаунт» на екрані входу.
- Адміністратор: admin / 1234 (тільки демонстраційний режим).

Фото позицій беруться з assets/menu_photos, завантажених адміністратором.
Вага зберігається в полі weight_g (необов'язкове) у редакторі меню.
Рецептура береться з SQLite; клієнт не може її змінювати.

Увага:
- Кошик тимчасовий, після перезапуску не зберігається.
- Онлайн-оплати немає: вибір «Картка» фіксує спосіб оплати.
- Списання інгредієнтів при оформленні замовлення поки не реалізоване.
- Нові акаунти створюються з хешованими паролями (PBKDF2).
- Демонстраційний пароль admin/1234 НЕ підходить для реального магазину.
