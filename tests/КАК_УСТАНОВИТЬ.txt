PIZZA HOUSE — «КОРИСТУВАЧІ» + «ПРАЦІВНИКИ»
============================================

ЭТО ОБНОВЛЕНИЕ ДЛЯ ТЕКУЩЕЙ МОДУЛЬНОЙ ВЕРСИИ PIZZA HOUSE.

1. Полностью закройте приложение и Visual Studio (при необходимости).
2. Сделайте резервную копию всей папки проекта, ОСОБЕННО pizza_house.db.
3. Из архива скопируйте три файла в проект:
   - people_db.py        -> C:\Users\user\Desktop\proj\pizzaHouse\people_db.py  (новый)
   - ui\people_page.py   -> C:\Users\user\Desktop\proj\pizzaHouse\ui\people_page.py (новый)
   - ui\app.py           -> C:\Users\user\Desktop\proj\pizzaHouse\ui\app.py (заменить)
4. Не заменяйте database.py, pizza_house.db или другие файлы.
5. Запустите pizzaHouse.py через Ctrl+F5 и войдите администратором.
6. Откройте вкладки «Користувачі» и «Працівники».

ВОЗМОЖНОСТИ:
- 9 тестовых клиентов и 8 сотрудников из исходного Excel появляются при первом запуске.
- Добавление, редактирование, удаление, поиск.
- ID клиентов: C1042, C2087 ...; новых: C9733, C9734 ...
- ID сотрудников: E1024, E2158 ...; новых: E8752, E8753 ...
- Если удалили запись, ID больше не используется повторно.
- Все изменения сохраняются в прежней pizza_house.db.
- В таблице для широких полей есть горизонтальная полоса прокрутки ВНИЗУ.
- Кнопки «Змінити» и «Видалити» находятся в колонке «Дії» справа.
- «Головна» показывает реальное количество клиентов и сотрудников.
- Клиентская самостоятельная регистрация и привязка к заказам ПОКА НЕ РЕАЛИЗОВАНЫ.
  Позже оформление заказа сможет вызывать add_customer(...),
  а заказ ссылаться на поле customers.customer_id.
- Демонстрационный вход client/1234 по-прежнему не связан с таблицей клиентов.

Примечания:
Даты хранятся в формате ГГГГ-ММ-ДД, телефоны — строками (начальный ноль сохраняется).
В Excel телефоны были записаны числами без ведущего нуля; для примеров он восстановлен.
Поля таблиц соответствуют листам «Користувачі» и «Працівники» исходного Excel.
Новые внешние библиотеки для этого обновления не нужны.

После проверки работы обновите файлы Git через Commit + Push.
